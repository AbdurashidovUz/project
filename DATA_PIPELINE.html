Data Flow
🌐 Hipolabs Universities API EXTERNAL API
Free, open REST API with ~9,700 real universities worldwide. Provides name, country, web_pages, and domains — no API key required.
↓
⚙️ scripts/fetchRealUniversities.mjs NODE SCRIPT
Queries the API per country, deduplicates results, and enriches each university with country-appropriate tuition ranges, IELTS scores, deadlines and scholarship flags.
↓
🗄️ supabase/universities_seed.sql SQL SEED
146 INSERT statements generated from real API data. Run in Supabase SQL Editor to populate the live database.
↓
🔷 Supabase PostgreSQL Database DATABASE
Stores all university records. The app queries this with filters (country, tuition, IELTS, scholarship). Falls back to mockUniversities.ts if Supabase is offline.
↓
⚛️ src/lib/api.ts → React App FRONTEND
TypeScript API layer wraps Supabase queries with filters, timeouts, and fallback logic. Results flow into React components.
API Call — Hipolabs
🌐
One HTTP GET per country. No authentication, no rate limits, no API key.

// ── Highlighted: External API Call ────────────────────────

async function fetchUniversitiesForCountry(apiName, take) {
  const url = `http://universities.hipolabs.com/search?country=${encodeURIComponent(apiName)}`;
  const res  = await fetch(url);
  const data = await res.json();

  // data shape from API:
  // [{ name, country, web_pages: ["https://..."], domains, alpha_two_code }]

  const filtered = data.filter(u =>
    u.name && u.web_pages?.length > 0 &&
    !u.name.match(/community college|polytechnic|nursing/i)
  );

  const unique = deduplicate(filtered);
  unique.sort((a, b) => a.name.length - b.name.length);
  return unique.slice(0, take);
}

Live App Query — src/lib/api.ts
🔷
The frontend queries Supabase directly with filters. A 5-second timeout prevents hanging when the backend is offline.
 src/lib/api.ts — fetchUniversities() 
export async function fetchUniversities(filters?: UniversityFilters) {
  let query = supabase.from('universities').select('*');

  // Apply filters dynamically
  if (filters?.countries?.length)
    query = query.in('country', filters.countries);

  if (filters?.ieltsScore)
    query = query.lte('ielts_requirement', filters.ieltsScore);

  if (filters?.hasScholarship)
    query = query.eq('has_scholarship', true);

  if (filters?.searchQuery)
    query = query.or(`name.ilike.%${q}%,country.ilike.%${q}%`);

  const { data, error } = await withTimeout(query, fallback, 5000);

  if (error || !data) {
    // ↓ Fallback to mockUniversities.ts when Supabase is offline
    return [];
  }
  return data;
}
